kane-loop

A verification loop between your coding agent and Kane CLI

  • git diff → the saved _test.md flows that cover it → headless Kane replay
  • failure → .kane/last-failure.md: step, expected vs seen, Kane triage, culprit diff, evidence
  • MCP tools so Cursor, Claude Code or Codex can verify, read, fix and re-run on their own
Everything in this video is a real run of kane-cli 0.10.3 against the Splitly demo app on localhost (terminal output captured, waits shortened).

How it works

agent edits code ──► kane-loop verify / watch / MCP verify_changed │ git diff ∩ <!-- kane-loop covers: … --> in each flow ▼ kane-cli testmd run flows/x_test.md --agent --headless --no-adaptive-heal │ recorded steps replay in real Chrome: 0 credits, ~7 s per flow ▼ NDJSON stream ──► one summary line + .kane/last-failure.md │ expected (recorded check) vs seen (replayed value), │ Kane's triage, the culprit diff, screenshot, evidence pack ▼ MCP last_failure ──► agent fixes the app ──► MCP rerun_failed ──► green
